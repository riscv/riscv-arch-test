# Zvbb: rule-derived tests

One test per `norm:` rule of `src/unpriv/zvbb.adoc` for the instructions that are only in Zvbb (vbrev, vclz, vctz,
vcpop, vwsll) and for the chapter's EEW rules. The rules of the instructions that Zvkb shares with Zvbb (vandn,
vbrev8, vrev8, vrol, vror) are in `tests_ai/Zvkb`, which every Zvbb hart also runs. Generated by
`tests_ai/gen/gen_Vzv.py` (helpers in `gen/vzvlib.py`).

## How the extension is tested

- **Data path.** Operands are `.word` arrays loaded with `vle<SEW>.v`; results are stored with `vse<EEW>.v` and checked
  word by word, so one expected word serves RV32 and RV64. Expected values come from the instruction descriptions
  and operation pseudocode.
- **Configuration.** LMUL=8 (LMUL=4 for the widening vwsll) with vl <= 8, so every case fits VLMAX for any VLEN >= 32.
  SEW=64 cases are under `#if ZVE64X_SUPPORTED`.
- **Edges named in the rules.** Zero inputs (vclz and vctz give SEW), single bits at every byte position, all ones,
  MSB, 0x55../0xAA..; vwsll zero-extends (MSB-set data), uses only log2(2*SEW) shift bits (amounts SEW..2*SEW,
  all-ones vs1, rs1 with random upper bits, uimm up to 31).
- **EEW rules.** `Zvbb_eew` runs every Zvbb instruction at SEW=8, 16 and 32 (vwsll at 8 and 16); `Zvbb_eew_Zve64x`
  requires Zve64x and covers SEW=64 and vwsll at SEW=32. `Zvbb_dependent_Zve32x` checks the Zve32x features the
  dependency guarantees (SEW <= 32 legal at LMUL=1, VLEN >= 32, integer vector arithmetic).
- **Mutation check.** `gen_Vzv.py` has a `MUTANTS` dict (`Vzv:<mutant>`); every mutant fails a test on Sail.

## Rules not tested here

None: every rule of the chapter has a test here or in `tests_ai/Zvkb`. Value crosses (SEW x LMUL x policy, masking)
are left to the ACT Zvbb test plan.

## Subtleties

- vctz of zero: the description sentence "The result for zero-valued inputs is the value SEW" is commented out in
  the vctz section, but the operation's loop gives SEW; the test expects SEW.
