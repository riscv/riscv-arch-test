[NOTE]
====
* spec:
* As implementations are free to implement WFI as a NOP, software must explicitly check for
* any relevant pending but disabled interrupts in the code following an WFI, and should loop
* back to the WFI if no suitable interrupt was detected. The mip or sip registers can be
* interrogated to determine the presence of any interrupt in machine or supervisor mode
* respectively.
====
