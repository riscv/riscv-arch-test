| Verify that PMP permissions are checked during hardware update of PTE.A
| With menfcfg.ADUE = {0/1}: Check that page tables are accesssed with S permission during hardware page table hardware A bit update. +
Set up VM page table with PMP.W=0 pointing to page in default region. +
Leaf page tables have full access, AD = 00 +
With satp pointing to each top-level page table, {lw/sw/jalr} to some virtual address. +
Expect store access fault on all 3 instructions when W = 0 iff Svadu enabled, because it attempts to write A bit and doesn't have access
| If ADUE = 0: load/store/fetch page fault +
If ADUE = 1 and PMP W = 0, store access fault from HPTW trying to update PTE +
If ADUE = 1 and PMP W = 1, no fault
| 2 ADUE * 3 page tables * 3 types of access
| AD ->  accessed (A) and dirty (D) bit. The A bit indicates the virtual page has been read, written, or fetched from since the last time the A bit was cleared. The D bit indicates the virtual page has been written since the last time the D bit was cleared.... To assign look at page 135
