| Basic load
| Set up non-identity G and VS-stage page tables. In {M, HS, U (with hstatus.HU = 1): Write a random value to scratch. hlvx.hu, hlvx.wu from scratch.  Random source and destination registers.

| Basic store
| Set up non-identity G and VS-stage page tables. In {M, HS, U (with hstatus.HU = 1): Write a random value to scratch. hsv.b, hsv.h, hsv.w to scratch.  For rv64, also test hsv.d.  Random source and destination registers and values.

| Basic fence

| 3 modes * 2 TVM * 2 VTVM
