# Zvfbfmin: rule-derived tests

One test per `norm:` rule of `src/unpriv/zvfbfmin.adoc`. Generated by `tests_ai/gen/gen_Vzv.py`.

## How the extension is tested

- **Encodings** (`*_enc`): the instructions run from `.word` encodings built from the diagrams' fields, with vm=1
  and with vm=0 and v0 = 0b0101 (inactive elements undisturbed under mu).
- `vfncvtbf16-f-f-w_op`: one element per instruction so each case's fflags is checked; rounding comes from `frm`
  (the instruction has no rm field): ties under all five modes (to even, odd, negative), overflow from 0x7f7fffff
  (infinity or the largest finite value by mode), quiet and signaling NaNs with payloads (canonical 0x7fc0; NV for
  signaling), infinity and -0, and FP32 subnormals: 0x007fffff rounds to 2^-126 with NX only under RNE because
  tininess is detected after rounding, but sets UF under RTZ; 0x00408000 ties with UF|NX.
- `vfwcvtbf16-f-f-v_op`: exact widening (the encoding shifted by 16, no flags) of normal, subnormal, -0, -infinity
  and the largest finite value under several frm values; quiet NaN -> 0x7fc00000 without flags, signaling NaN ->
  0x7fc00000 with NV.
- `Zvfbfmin_depends_Zve32f`: vfadd/vfmul at SEW=32.

## Rules not tested here

- `vfncvtbf16-f-f-w_sew_rsv`, `vfwcvtbf16-f-f-v_sew_rsv`: SEW other than 16 is reserved.

## Subtleties

- The BF16 rules used for the expected values are tagged in `zfbfmin.adoc`: `bf16_subnorm` (tininess after
  rounding) and `bf16_canonical_nan` (0x7fc0). Those tags belong to a Zfbfmin suite; they are context here.
