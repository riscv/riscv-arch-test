==== Zkt Constant-Time Instructions

Zkt requires the instructions it lists to have data-independent latency.
Latency is not architecturally visible, and measuring it with a cycle counter is unreliable: instruction fetch, branch prediction, superscalar issue, and out-of-order execution make the count depend on where the instruction is and what surrounds it, not only on its operand data.
Zkt is therefore out of scope for certification and is not tested (<<t-untested>>).
