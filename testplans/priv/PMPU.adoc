5+| See PMPM for general information. +
Tests configure PMP in M-mode, and then run in U-mode unless otherwise stated

5+| PMP RWX

| cp_cfg_X
| The ...X bits, when set, indicate that the PMP entry permits ... instruction execution
| Check that X alone determines execute access. +
Configure PMP and switch to U mode. +
Fetch instruction with pmpcfg_i.L={0/1}, all legal pmpcfg_i.XWR +
Observe access faults for restricted execution regions. L does not affect results
| 2 L * 6 XWR
| pmp_cfg_permissions +
pmp_access_fault_exception +
pmp_rwx_check

| cp_cfg_RW
| The R, W, ...bits, when set, indicate that the PMP entry permits read, write
| Check that WR bits control write/read access for every type of load and store. +
Configure PMP and switch to U mode. +
Attempt all types of reads and writes with pmpcfg_i.L={0/1}, all legal pmpcfg_i.XWR +
Observe proper access faults for restricted read/write regions. Exclude lwu, ld, sd in RV32
| 2 L * 6 XWR * (7 loads + 4 stores)
| pmp_cfg_permissions +
pmp_access_fault_exception +
pmp_rwx_check +
pmp_l_bit_m_mode_enforcement

| cp_none
| If no PMP entry matches an S- +
mode or U-mode access, but at least one PMP entry is implemented, the access fails.  If at least one PMP entry is implemented, but all PMP entries’ A fields are set to OFF, S and U-mode memory accesses will fail.
| U-mode access fails when all PMP are off. +
With all pmpcfg, pmpaddr = 0 (including background top PMP entry), switch to U-mode.  Immediate trap, terminate program.
| 3 types of access
| pmp_no_entry_match +
pmp_rwx_check

5+| PMP Address-Matching Modes

| cp_cfg_A_off
| A 0 OFF Null region (disabled)
| Check that OFF doesn't match. +
Configure PMP and switch to U mode. +
pmpcfg_i.L = 0, pmpcfg_i.A = OFF, pmpcfg_i.XWR = 000, pmpaddr_i = all 1s +
{lw/sw/jalr} in the region +
Observe success because OFF region doesn't match, and default region succeeds.
| 3 types of access
| pmp_a_field_off +
pmp_load_fault +
pmp_store_fault

| cp_cfg_A_napot
| NAPOT ranges make use of the low-order bits of the asscoiated address registers to encode the size of the range.
| Check XWR controls accesses in matching NAPOT region. +
Configure PMP and switch to U mode. +
For a standard region with pmpcfg_i.L = 0, pmpcfg_i.A=NAPOT, all legal pmpcfg_i.XWR: make {lw, sw, jalr} at that start of region, start - 4, start + 4, highest word in region, just beyond top of the region.  Observe proper access faults for restricted regions, and accesses beyond the region should succeed.
| 6 XWR * 3 types of access * 5 addresses
| pmp_napot_encoding_low_bits +
pmp_access_fault_exception

| cp_cfg_A_na4
| NA4: Naturally-aligned four-byte region.
| Check XWR controls accesses in matching NA4 region. +
G=0 Only +
Configure PMP and switch to U mode. +
With pmpcfg_i.0 = 1, pmpcfg_i.A=NA4, all legal pmpcfg_i.XWR, reasonable address in pmpaddr: make {lw, sw, jalr} at that address, that address + 4, just beyond top of the region.  Observe proper access faults for restricted regions, and accesses beyond the region should succeed.
| 6 XWR * 3 types of access * 3 addresses
| pmp_a_field_napot_na4 +
pmp_access_fault_exception

| cp_cfg_A_tor
| If TOR is selected, the associated address register forms the top of the address range, and the preceding PMP address register forms the bottom of the address range.
| Check XWR controls accesses in matching TOR region. +
Configure PMP and switch to U mode. +
With pmpcfg_i.L =0, pmpcfg_i.A = TOR, all legal pmpcfg_i.XWR, default TOR region, address-g in pmpaddr_i-1: {lw, sw, jalr} address, address-4, address-g, address-g-4.  Observe proper access faults for restricted regions.
| 6 XWR * 3 types of accesses, 4 addresses
| pmp_a_field_tor +
pmp_access_fault_exception

5+| MPRV

| cp_mprv
| PMP checks are appleid to all accesses whose effective privilege mode is S or U, including ... data access in M-mode when the MPRV bit in mstatus is set and the MPP field in mstatus contains S or U.
| Check L bit doesn't matter with MPRV setting to lower privilege mode. +
Configure PMP in M-mode. Set mstatus.MPRV = {0/1}, mstatus.MPP = {11 / 00}.  Stay in M-mode. +
{lw/sw/jalr} with pmpcfg_i.L={0/1}, XWR = {000, 111} +
Observe access faults for restricted execution regions even with L = 0 in effective U mode.
| 2 L * 3 MPP * 2 XWR * 3 instructions * 2 MPRV
| pmp_check_priv_modes +
pmp_access_fault_exception

5+| Register Access

| cp_pmpaddr_access_u

Should throw illegal instruction faults.

| pmp_csr_mode +
pmp_addr_registers

| cp_pmpcfg_access_u
| PMP CSRs are only accessible to M-mode.

| 16 CSRs
| pmp_csr_mode +
pmp_cfg_rv32_layout +
pmp_cfg_rv64_layout
