Tests if Sm exists (not run for RVA23 certification)

Boot to MMODE, run tests in each supported priv mode of <M,S,U,VS,VU>

Reference model needs to know if each of the 10 types of interrupts are supported

menvcfg.STCE = 0 unless otherwise stated

mideleg = 0s unless otherwise stated.

mtvec.MODE uses boot value

RVTEST_SET_MTI_INT writes mtimecmp = 0 (with tsbi if necessary)

Define ways to cause all of the interrupts that are standard as much as possible, only need RV macros for special stuff

.InterruptsSm Coverpoints
[cols="2,1,4,2,1,2", options=header]
|===
| Coverpoint | Goal | Feature Description | Expectation | Bins | Normative Rule

| cp_trigger
| Assert each interrupt
| For <type> = {LCOFI, MTI, MSI, MEI, STI, SSI, SEI, VSTI, VSEI, VSSI} +
setup_interrupts_sm +
trigger_interrupts_<type>
| supported interrupts will fire if +
- not delegted to a lower priv mode than the current mode +
- enabled by MIE if running in M mode and not delegated
| 10 int * 5 priv * 2 MIE * 2 SIE * 2 vecMODE * 2 mideleg
| mstatus_mie_op +
mstatus_sie_op +
mstatus_xie_intr_en_dis +
mstatus_xpie_op +
mstatus_xpp_op +
mstatus_xpie_trap_op +
mstatus_xie_trap_op

| cp_trigger_reg
|
| Same as cp_trigger, but use mip.SEIP, mip.SSIP, and sip.SSIP rather than macros.
| same as above
| 3 int * 5 priv * 2 MIE * 2 SIE * 2 vecMODE * 2 mideleg
|

| cp_trigger_sti_sstc
| STI with SSTC
| if SSTC_SUPPORTED: +
setup_interrupts_sm +
write menvcfg.STCE = {0/1} +
trigger_interrupts_SSTC
| STI should trigger if +
STCE = 1 +
- when mideleg = 0, MIE = 1, running in M mode, +
anytime running in non M mode,
| 5 priv * 2 STCE * 2 MIE * 2 SIE * 2 vecMODE * 2 mideleg
|

| cp_enable
| Enables control interrupts
| mideleg = 0 (if S_SUPPORTED) +
write mstatus.MIE = 1 +
For <type> in <types above>: +
mie = {1 in type, 1s everywhere except type} +
RVTEST_SET_<type>_INT +
RVTEST_IDLE_FOR_INT +
RVTEST_CLR_<type>_INT
| Interrupt if mie and mip match
| 10 int * 5 priv * 2 mie
|

| cp_priority_mip
| Priority of pending interrupts
| mideleg = 0 (if S_SUPPORTED) +
write mstatus.MIE = 1 +
write mie = 0s +
RVTEST_SET_<type>_INT (10 choose 2) pairs of mip.<TYPE1, TYPE2> +
write mie = 1s +
RVTEST_IDLE_FOR_INT +
RVTEST_CLR_<type>_INT for both
| if supported - higher priority interrupt will fire
| 45 int * 5 priv
|

| cp_priority_mie
| Priority of enabled interrupts
| mideleg = 0 (if S_SUPPORTED) +
write mstatus.MIE = 1 +
write mie = 0s +
RVTEST_SET_<type>_INT for all 10 types +
write mie with two ones for all (10 choose 2) pairs +
RVTEST_IDLE_FOR_INT +
RVTEST_CLR_<type>_INT for all
| if supported - higher priority enabled interrupt will fire
| 45 int * 5 priv
|

| cp_priority_mideleg
| Priority of delegated interrupts
| if S_SUPPORTED: +
write mstatus.MIE = 1 +
write mie = 0s +
RVTEST_SET_<type>_INT (10 choose 2) pairs of mip.<TYPE1, TYPE2> +
mideleg = 0s except {1 in TYPE1, 1 in TYPE2} (one at a time) +
write mie = 1s +
RVTEST_IDLE_FOR_INT +
RVTEST_CLR_<type>_INT for both
| if supported - undelegated interrupt takes priority
| 21 int * 2 mideleg * 5 priv
|

| cp_wfi
| WFI waits until timer interrupt
| Only test if machine timer interrupts are supported +
Do not test in U mode if S_SUPPORTED +
mideleg = 0 (if S_SUPPORTED) +
write mstatus.TW = 0 (also 1 in M-mode) +
write mstatus.MIE = {0/1} +
write mie.MTIE = 1 +
RVTEST_SET_MTI_SOON to set MTIMECMP = TIME + RVMODEL_TIMER_INT_SOON_DELAY +
do { +
WFI instruction +
} until MTI has fired (see Zawrs) +
RVTEST_CLR_MTI_INT
| Wait for timer interrupt.  MIE, SIE and TW should not affect results.
| 4priv * 2 MIE + M mode * 2 MIE * 2 TW
| mstatus_tw_op

| cp_wfi_timeout
| WFI waits until timeout
| Only applies to modes < M +
write mstatus.TW = 1 (also 0 in U-mode if S_SUPPORTED) +
write mstatus.MIE = {0/1} +
write mie.MTIE = {0/1} +
WFI instruction
| Note: may need sufficient Sail parameter to determine if we get illegal instruction or if WFI just retires.  Or may need to accept both behaviors.
| 4 priv * 2 MIE * 2 MTIE
| mstatus_tw_op +
mstatus_tw_umode_op +
MSTATUS_TW_TIME_LIMIT +
MSTATUS_TW_ALWAYS_ILLEGAL

| cp_write_stip_sstc
| test STIP writability when SSTC supported
| if SSTC_SUPPORTED: +
In M mode +
mideleg = 0 +
mie = 0s +
Write menvcfg.STCE = 1 +
Write stimecmp = 0s/1s x mip.STIP = {0/1} +
Read back STIP & sigupd +
Clear STIP through stimecmp
| mip.STIP is controlled by stimecmp, ignores writes.
| 2 stimecmp x 2 STIP
|

|===
