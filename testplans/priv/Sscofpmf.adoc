6+| To test Sscofpf, the user must give values to the following RVMODEL macros.  If any are undefined and SSCOFPMF_SUPPORTED, error.

| RVMODEL_MHPMCOUNTER
| Name of a hpmcounter CSR to test (e.g. mhpmcounter3)

| Name of a event CSR to test (e.g. mhpmevent3)

| RVMODEL_MHPMEVENT_VAL
| Value to put in the event CSR to make it count.
|
|
|
|

| RVMODEL_MHPMEVENT_CODE
| Code that increments the event counter (shouldn't trash certain registers), should be able to run in all privilege modes

6+| These values need to be different in sail_macros.h to support how Sail will do this (https://github.com/riscv/sail-riscv/issues/1733)

6+| Only one of the HPM counters is tested because the spec does not require multiple counters supported even when Zihpm is active.

6+| Tests are performed in Sm/S/U for SscofpmfSm/S/U suites

6+| Use T-SBI calls where necessary to access machine mode CSRs from lower privilege modes.

| cp_xinh_inhibits_xmode
| xINH bit inhibits counting in {M/S/U}-mode
| For SscofpmfSm/S/U: +

RVMODEL_MHPMEVENT[62:58] = 32 combinations (exclude unsupported modes) +
RVMODEL_MHPMEVENT[63] = 0 (OF = 0) +
RVMODEL_MHPMCOUNTER = 0 +

Read RVMODEL_MHPMCOUNTER and check if nonzero +

| RVMODEL_HPMCOUNTER becomes nonzero iff xinh = 0
| 2^5 combinations +

overflows

RVMODEL_MHPMCOUNTER should not be all 0s or all 1s +

| cp_scountovf_shadow
| scountovf shadows OF bits of mhpmenvent3:31
| For SscofpmfSm/S, if (S_SUPPORTED): +
mcounteren = all 1s +
Write patterns to mhpmevent3...31.OF: all 0s, all 1s, walking 1s. +

| scountovf should match 1s in OF fields
| 31
| norm:scountovf_op

| cp_scountovf_mcounteren
| scountovf masked by mcounteren
| For SscofpmfSm/S, if (S_SUPPORTED): +

Write patterns to mcounteren: all 0s, all 1s, walking 1s +
Read scountovf
| In M-mode, scountovf  = value written (except bits 2:0 are always 0) +
in S-mode, scountovf =value written & mcounteren (except bits 2:0 are always 0)
| 3 OF * 31 mcounteren
| norm:scountovf_mmode_read_access +
norm:scountovf_smode_read_access

| Access hpm CSRs

| 5 accesses * 31 CSRs
| norm:scountovf_mmode_read_access +
