# Ssu64xl: rule-derived tests for UXLEN=64

One test for the only `norm:` rule in `src/priv/ssu64xl.adoc`. RV64 only: the file passes trivially on RV32.
Generated by `tests_ai/gen/gen_Sx.py`. Mutants are named `Sx:uxl_*` and `Sx:u_32bit`.

## How the extension is tested

- **Holding 2.** `sstatus.UXL` is written with 2 through csrs/csrc and through a whole-register csrw. It must read
  2 in sstatus and in mstatus (read through T-SBI).
- **Other values.** After a write of 1 (optional, so 1 or 2 is legal) and of the non-legal values 0 and 3 (which
  must read 1 or 2), UXL=2 is written again and must read 2. mstatus.UXL=2 written in M-mode is also seen in sstatus.
- **UXLEN=64 in effect.** U-mode runs a 64-bit shift and ADDIW after each write of 2. U-mode is never entered with
  UXL=1.

## Rules not tested here

- All rules are tested.

## Subtleties

- `vsstatus.UXL` is not covered by Ssu64xl, so it is left to the H suite.
