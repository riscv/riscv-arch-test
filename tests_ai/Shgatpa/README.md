# Shgatpa: rule-derived tests for hgatp modes

One test per `norm:` rule in `src/priv/shgatpa.adoc`. Generated by `tests_ai/gen/gen_Sx.py`. Mutants:
`Sx:x4_missing_sv48`, `x4_missing_sv32`, `x4_drops_top` and `no_bare`.

## How the extension is tested

- **Every SvNNx4.** For each SvNN that satp accepts, hgatp must accept SvNNx4.
  - satp modes are probed in HS-mode with a root that identity-maps the image.
  - hgatp modes are probed by writing MODE and reading it back.
- **The mode translates.** HLV.W (vsatp Bare) of a guest physical address with both extra GPA bits set must read the
  page that the SvNNx4 table maps there. On RV32 that GPA is above 4 GiB, so it is reached through a VS-stage Sv32
  leaf when vsatp accepts Sv32.
- **Bare.** hgatp = 0 reads 0 and does not translate:
  - at the start;
  - after a translating x4 mode that remapped the same address;
  - for VS-mode code.

## Rules not tested here

- All rules are tested.

## Subtleties

- **WARL.** hgatp is WARL: a write with an unsupported MODE leaves some legal value, so support is judged by MODE
  reading back.
