| Coverpoint | Goal | Feature Description | Expectation | Bins

| cp_mcsr_access
| Access to all M-mode CSRs
| csr read, write all 1s, write all 0s, set all 1s, clear all 1s, write back inital value of each register below plus read-only mvendorid, marchid, mimpid, mhartid, mconfigptr
| Traps on writes to read-only registers.  Otherwise writable bits match reference model.
| (14+5) regs * 6 ops + +
mcause (WLRL), mstatus/h (WPRI), menvcfg/h (WPRI), mseccfg/h (WPRI) could be weird/hard to model

| cp_mcsrwalk
| Walking 1s and 0s in each writeable M-mode CSR
| Set and clear each bit of each writable M-mode CSR to exercise bitfields: mstatus, medeleg, mideleg, mie, mtvec, mcounteren, mscratch, mepc, mcause, mtval, mip, menvcfg, mseccfg.  For RV32 also mstatush, medelegh, menvcfgh, mseccfgh, mcountinhibit, mhpmevent31:3..  misa is fussy to model and is tested in cp_misa* instead..
| Writable bits match reference model.
| 14 regs * (64 set + 64 clear)

| cp_misa_mxl
| misa.MXL
| Attempt to write all four values to misa.MXL, clear, set..  Read back
| matches MXLEN and does not change
| 7 + +
Other MISA bits are unpredictable and thus not tested.

| cp_misa_dependencies
|
| Attempt to write I, E = 1.  E should read 0 if I reads 1 +
Attempt to write I, E = 0.  One should read 1 +
Attempt to write F=0, D=1.  D should read 0 if F reads 0 +
Attempt to write F = 1, D = 0, Q = 1. Q should read 0 if D reads 0 +
Attempt to write S = 1, U = 0.  S should read 0 if U = 0 +
Attempt to write H = 1, S = 0.  H should read 0 if S = 0 +
Attempt to write H = 1, S = 1, U = 0.  H should read 0 if U = 0
| See tests
| 7

| cp_misa_clear_c
|
| Attempt to clear C when subsequent instruction is not a multiple of 2.  C should not change.
| C should not change
| 1

| cp_csrr_insufficient_priv
| Debug registers should be inaccessible from M-mode
| Read Debug CSRS 7B0-7BF
| Illegal Instruction
| 16

| cp_csrw_readonly
| Read-only registers should trap when written
| Write read-only CSRs (C00-FFF)
| Illegal Instruction
| 1024 CSRs

| cp_cntr_access
| Access to all 32 counters
| csr_read, write nonzero, write 0, set nonzero, clear all for each of for mcycle, minstret, mhpmcounter31...3. If RV32 is supported, also do mcycleh, minstreth, mhpmcounterh31...3.  Read back value and check if it is within some threshold of the written value (because counters will continue to increment).
| Writable bits match reference model.
| 32 regs * 6 ops

| cp_mtime_write
| Writing memory-mapped MTIME shows up in time CSR
| If Zicntr is supported, Write walking 1s and 0s to memory-mapped mtime, read back from time CSR
| Time reflects memory-mapped mtime. Difference should be small.
| Presently just writing one value

| cp_inhibit
| mcountinhibit prevents counting
| With mcountinhibit[2/0] = {0, 1}, read mcycle and minstret multiple times and check whether they increment.
| Count when not inhibited, remain constant when inhibited
| 2

| cp_mcause_write
| Legal values can be written to mcause
| with interrupt = 1: 0-13 +
with interrupt = 0: 0-23
| writes mcause
| 81 values

| cp_mstatus_sd_write
| FS/VS/XS combinations can be written and SD is true when any are dirty.
| Write 1 and 0 to SD with FS/VS/XS all 0.  Write cross-product of all bits of SD/ FS/ VS/XS.  128 bins of writes.
| FS =1 iff any of FS/VS/XS are dirty.
| 2 SD * 4 FS * 4 VS * 4 XS = 128

| cp_mprivinst
| ecall and ebreak cause traps
| Execute ecall and ebreak in machine mode
| ecall and breakpoint exceptions
| 2

| cp_mret
| mret returns and affects status bits
| Execute mret in machine mode with cross-product of values written to mstatus.MPP/ MPRV/ MPIE/MIE.  Return to machine mode and MIE = 1 after each mret.
|
| 2 MPRV * 2 MIPE * 2 MIE = 8

| cp_sret
| sret returns and affects status bits
| Execute sret in machine mode with cross-product of mstatus.SPP/MPRV/TSR/SPIE/SIE
| Illegal instruction if TSR
| 2 SPP * 2 MPRV * 2 TSR * 2 SPIE * 2 SIE = 32

| cp_sret_s
|
| If S_SUPPORTED: +
Execute sret in supervisor mode with cross-product of all values of sstatus.SPP/SPIE/SIE, mstatus.TSR.  Return to supervisor mode after each sret. This differs from cp_sret_s in S that doesn't turn on mstatus.TSR (which would require illegal instructions not to be delegated in S mode to avoid a sret trap loop).
|
| sepc should be pointing two instructions ahead.

| cp_scsr_from_m
|
| If S supported, read/write/set/clear each S-mode CSR: sstatus, scause, sie, stvec, scounteren, senvcfg, sscratch, sip, excluding bit 33 of senvcfg as it results in an invalid PMM field.  sepc and stval are not tested because it is hard to express what values are legal.
|

[NOTE]
====
* Sm does not access unsupported lower privilege mode CSRs because they are reserved if not implemented, and their behavior is UNSPECIFIED.
* If F is mutable, zeroing it should also zero D and Q and V. Same with D zeroing Q and V. Zeroing U should zero S.
* Writing misa may increase IALIGN, e.g., by disabling the "C" extension. If an instruction that would write misa increases IALIGN, and the subsequent instruction’s address is not IALIGN-bit aligned, the write to misa is suppressed, leaving misa unchanged."
====
