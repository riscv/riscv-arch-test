The following CSR accesses and instructions should be exercised in supervisor mode.  All inherently require Zicsr.

[[t-SsstrictS-coverpoints]]
.SsstrictS Coverpoints
[cols="2,1,3,3,2,3", options=header]
|===
| Coverpoint | Goal | Feature Description | Expectation | Bins | Test Hints

| cp_csrr
| CSR Accesses
| Read all 4096 CSRs from S-mode (CSRR with rd≠x0). Skips: satp (0x180, would enable virtual memory), custom S/H CSRs (0x5C0-0x5FF, 0x6C0-0x6FF, 0x9C0-0x9FF, 0xAC0-0xAFF, 0xDC0-0xDFF, 0xEC0-0xEFF).
| S-mode CSRs return values; M-mode/H-mode/debug CSRs raise illegal-instruction from S-mode.
| One bin per CSR 0x000–0xFFF (excluding skips), executed from S-mode
| Switch to S-mode (ecall with a0=1) before CSR sweep. +
Fast trap handler must be installed from M-mode first. +
Excludes satp to avoid activating virtual memory.

| cp_csrw_corners
| CSR Accesses
| Write all-zeros and all-ones to every CSR from S-mode. Skips satp and same custom CSRs as cp_csrr.
| S-mode writable CSRs accept writes; read-only or higher-privilege CSRs trap.
| Two bins per CSR: write 0 and write all-ones
| Same as SsstrictSm but with mode switch to S-mode first.

| cp_csrcs
| CSR Accesses
| Set and clear all bits of every CSR from S-mode using CSRRS/CSRRC with rs1=all-ones.
| Same as cp_csrw_corners.
| Two bins per CSR: CSRRS all-ones and CSRRC all-ones from S-mode
| CSRRS/CSRRC with x=−1 from S-mode.

| cp_shadow_m
| Shadow CSR verification (M-mode write)
| Write all-ones and all-zeros to mstatus, mie, mip from M-mode, verifying the S-mode shadow registers (sstatus, sie, sip) reflect the correct subset of bits. Also write all-ones/zeros to sstatus, sie, sip from S-mode and verify the M-mode shadows reflect the changes.
| mstatus↔sstatus, mie↔sie, mip↔sip are consistent: bits shared between the views have the same value; sstatus-only bits do not appear in mstatus and vice versa.
| 6 bins: {mstatus, mie, mip} × {write 0, write 1s} from M-mode +
6 bins: {sstatus, sie, sip} × {write 0, write 1s} from S-mode
| From M-mode: csrrw x0, mstatus, x2 (x2=-1) then csrrw x0, mstatus, x0. +
Implemented as inline code after S-mode CSR sweep.

| cp_illegal_instruction
| Illegal Uncompressed Instructions
| Same encoding sweep as SsstrictSm but executed from S-mode. All reserved/illegal encodings must trap; M-mode-only instructions (MRET, debug CSR access) also trap from S-mode.
| Identical to M-mode case — illegal-instruction exception per reserved encoding.
| Same as SsstrictSm cp_illegal_instruction but with S-mode priv_mode context
| Switch to S-mode before #include of SsstrictInstr-Tests.h. +
mstatus.FS/VS must be enabled from M-mode before switching.

| cp_illegal_compressed_instruction
| Illegal Compressed Instructions
| Same compressed quadrant sweep (00/01/10) as SsstrictSm but from S-mode.
| Same as SsstrictSm — each reserved encoding traps.
| Same as SsstrictSm cp_illegal_compressed_instruction but S-mode context
| Switch to S-mode before #include of SsstrictInstrCompressed-Tests.h.

| cp_upperreg
| Instructions using x16-x31 from S-mode
| Same upper-register sweep as SsstrictSm but executed in S-mode. Tests that E-extension illegal-instruction behavior is consistent across privilege modes.
| If RV32E/RV64E: trap on x16-x31 access. If standard I: succeed. F regs always succeed.
| Same bins as SsstrictSm cp_upperreg, S-mode context
| Switch to S-mode first. Raw .word encodings for upper register positions.

| cp_misa_ext_disable
| Extension bits
| Same extension disable sweep as SsstrictSm but: disable misa bit from M-mode, switch to S-mode, execute instruction, switch back, re-enable. Extensions: A, B, C, D, F, H, I, M, Q, U, V (S-mode cannot disable S itself). U-mode entry with U=0 should trap.
| Each instruction executed in S-mode with misa bit cleared raises illegal-instruction. Entering U-mode with misa.U=0 should fail.
| One bin per extension per {M-mode-disable → S-mode-execute}
| M-mode: clear misa bit / ecall to S-mode / execute instruction / ecall back to M-mode / restore misa. +
U-mode entry: ecall(0) with misa.U=0 should trap.

| cp_reserved_frm
| Reserved FP rounding modes from S-mode
| Same as SsstrictSm cp_reserved_frm but executed from S-mode. Verify reserved FRM behavior is consistent across privilege levels.
| Same as SsstrictSm — FRM 5/6 reserved, mode 7 with DYN FRM=5/6/7 raises FP exception.
| 8 bins: FRM ∈ {0..7} with FADD.S in S-mode
| Switch to S-mode, then csrwi frm,N / fadd.s f0,f1,f2 for N=0..7.

|===

[NOTE]
