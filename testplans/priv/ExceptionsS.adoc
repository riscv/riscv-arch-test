The following exceptions should be exercised in supervisor mode unless otherwise noted.  All inherently require Zicsr.

[[t-ExceptionsS-coverpoints]]
.ExceptionsS Coverpoints
[cols="2,1,2,2,2", options=header]
|===
| Coverpoint | Goal | Feature Description | Expectation | Bins

| cp_instr_adr_misaligned_branch
| Instruction Address Misaligned
| Each type of branch taken to an address that is an odd multiple of 2 +
PC[1] = 0 and imm[1]=1
| Only throws an exception if C is not supported.
| 6 branches

| cp_instr_adr_misaligned_branch_nottaken
| Instruction Address Misaligned
| Each type of branch not taken to an address that is an odd multiple of 2
| No exception
| 6 branches

| cp_instr_adr_misaligned_jal
| Instruction Address Misaligned
| jal to an address that is an odd multiple of 2 +
PC[1] = 0 and imm[1]=1
| Instruction at multiple of 4.  Offset is an odd multiple of 2.
| 1

| cp_instr_adr_misaligned_jalr
| Instruction Address Misaligned
| jalr to an address that is an odd multiple of 2 and odd multiple of 2 + 1. +
Every combination of rs1_val[1:0] and offset[1:0]
| Only throws an exception if C is not supported.
| 4 rs1[1:0] * 4 offset[1:0]

| cp_instr_access_fault
| Instruction Access Fault
| Fetch instruction from unimplemented memory
| Access fault
| 1

| cp_illegal_instruction
| Illegal Instruction
| Executing instruction 0x00000000 and 0xFFFFFFFF
| throws an illegal instruction exception (trap and mcause)
| 2 instr

| cp_illegal_instruction_seed
| Illegal Read-only access to a CSR
| csrrs x*, seed, x0 throws illegal instruction as do +
csrrc x*, seed, x0 +
csrrsi x*, seed, 0 +
csrrci x*, seed, 0
| Illegal instruction exception
| 4 csr ops + +
*** this could be reserved and should be moved to an Zkr spreadsheet for all priv modes

| cp_breakpoint
| Breakpoint
| ebreak throws breakpoint exception +
also test when straddling 64B boundary
| throws breakpoint exception (trap and mcause)
| 1

| cp_load_address_misaligned
| Load Misaligned
| Attempt lh, lhu, lw, lwu, ld with every combination of three address lsbs: 000 - 111
| Might not cause exception
| 7 ops * 8 lsbs

| cp_load_access_fault
| Load Access Fault
| Attempt lb, lbu, lh, lhu, lw, lwu, ld from an illegal address (parameterized)
| Load access fault
| 7 ops

| cp_store_address_misaligned
| Store Misaligned
| Attempt sh, sw, sd with every combination of three lsbs: 000-111
| Might not cause exception
| 4 ops * 8 lsbs

| cp_store_access_fault
| Store Access Fault
| Attempt sb, sh, sw, sd from an illegal address (parameterized)
| Store access fault
| 4 ops

| cp_ecall_s
| ecall
| ecall from supervisor mode throws ecall supervisor exception (trap and mcause)
| ecall to M-mode (should not be delegated to S-mode because there would be no path to M-mode)
| 1

| cp_misaligned_priority
| Priority of exceptions
| Attempt lw and sw and fetch from memory location causing  access fault and misaligned
| System-dependent
| 3 ops

| cp_stvec
|
| Cause delegated exception in s and u mode with stvec != mtvec
| Delegates to stvec handler
| 2 modes

| cp_xstatus_ie
| Interrupt Enables
| ecall cross {mode = user/supervisor, mstatus.mie = {0/1}, mstatus.sie = {0/1}}
| xpie gets xie, xie gets 0
| 3 modes * 2 medleg * 2 mie * 2 sie

|===
