.Zama16b Coverpoints
[cols="2,1,3,1,1,2", options=header]
|===
| Coverpoint | Goal | Feature Description | Expectation | Bins | Normative Rule

| cp_zama16b_load
| Misaligned accesses are atomic
| For each op in {lw, lh, lhu, lb, lbu} + {ld, lwu for RV64} + {flw for F, fld for D, flq for Q, flh for Zfh}: +
Pick base address as multiple of 16 +
Issue instruction with offsets of [0, 16-size]
| No misaligned load fault
| Up to 11 ops * 16 offsets
| Misaligned loads, stores, and AMOs to main memory regions that do not cross a naturally aligned 16-byte boundary are atomic.

| cp_zama16b_store
| Misaligned accesses are atomic
| For each op in {sw, sh, sb} + {sd for RV64} + {fsw for F, fsd for D, fsq for Q, fsh for Zfh}: +
Pick base address as multiple of 16 +
Issue instruction with offsets of [0, 16-size]
| No misaligned store fault
| Up to 9 ops * 16 offsets
| Misaligned loads, stores, and AMOs to main memory regions that do not cross a naturally aligned 16-byte boundary are atomic.

| cp_zama16b_amo
| Misaligned accesses are atomic
| For each op in {amoswap.w, amoadd.w, amoand.w, amoor.w, amoxor.w, amomax.w, amomaxu.w, amomin.w amominu.w} + {.d flavors for RV64} + {b and h flavors for Zabha} + {amocas.w, d, q if supported}: +
Pick address as multiple of 16 + offset of [0, 16-size] +
Issue instruction
| No misaligned store/AMO fault
| Up to 39 ops * 12 offsets
| Misaligned loads, stores, and AMOs to main memory regions that do not cross a naturally aligned 16-byte boundary are atomic.
