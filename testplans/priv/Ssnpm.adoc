7+| For all test entries in this sheet, the following address patterns are used to exercise pointer masking behavior: +
Base addresses (A bits 63:48): +
0x0000 unaffected by pointer masking +
0x0001 bit 48 masked if PMLEN=16 but not 7 +
0x0100 bit 56 masked if PMLEN = 16 but not 7 +
0x0200 bit 57 masked if PMLEN = 16 or 7 +
0x8000 bit 63 masked if PMLEN = 16 or 7 +
0xFFFF bits 63:48 are masked if PMLEN = 16, only partially if PMLEN=7 +
0xFE00 bits 63:57 are masked if PMLEN = 16 or 7 +
0xFF00  bits 63:56 are masked if PMLEN=16, only partially if PMLEN=7 +
Masked address : +
For PMLEN= 16 ( PMM=11) +
Bare mode (PA): {0x0000} → upper bits forced to zero +
Sv39 / Sv48/Sv57 (VA): {0x0000, 0xFFFF} → upper bits follow sign bit (XLEN-PMLEN-1 = 64-16-1 = 47 bit ) +
For PMLEN= 7 (PMM= 10): +
Bare mode (PA): {0x00 / 7'b0} → upper bits forced to zero +
Sv39 / Sv48Sv57 (VA): {7'b0, 0x7F} → upper bits follow sign bit ( XLEN-PMLEN-1 = 64 - 7 -1 = 56 bit ) +
All virtual A_masked addresses map to physical addresses with upper bits = 0x0000. +
The lower bits of the address being tested point to a scratch memory location that can safely be read and written. +
Virtual addresses with leading 0s are identity mapped to the same physical address. +
Virtual addresses with leading 1s are mapped to another scratch memory location containing a different data value so that it can be distinguished whether the upper bits are handled correctly.

7+| Why do  we need a different page than scratch to map the VA with leading 1s? +
A' = scratch page (upper bits = 0x0000), pre-loaded with value_old, identity-mapped with VA with leading 0s(VA == PA). +
VAs with leading 1s are explicitly PTE-mapped to a separate  page pre-loaded with value_different. This separation is necessary because if both VAs mapped to the same PA, a read would return value_old regardless of whether masking actually occurred;  the page table itself would resolve both addresses to scratch, making it impossible to tell if the hardware masked the upper bits or simply followed the mapping. +
With a seperate page holding a distinct value, the outcome is unambiguous: returning value_old proves the upper bits were stripped and scratch was reached via masking; returning value_different proves the upper bits were used as-is and other different page was accessed instead. +
NOTE : We will take sv tests as reference to setup PTE to map VA with leading ones to a dedicated physical region.

| cp_pmlen_masking
| Verify that upper PMLEN bits are ignored for every memory-accessing instruction when pointer masking is enabled
| If pointer masking is enabled, addresses differing only in upper PMLEN bits access the same physical location. +
Test Environment: +
In S-mode set senvcfg.PMM={00 (PMLEN=0), 10(PMLEN=7), 11(PMLEN=16)}. Place known value_old in scratch memory. +
Let A' = scratch (upper bits = 0x0000). For VA with upper bits = 1: mapped to a separate page from scratch. +
Enable SUM bit so we can access user-space pages from S-mode +
Switch to U-mode and execute the following loop: +
For each PMM in {00, 10, 11} under SAT.MODES = { Bare,  Sv39, Sv48, Sv57 } : +
For each A_upper_bits in {0x0000, 0x0001, 0x0100, 0x0200, 0x8000, 0xFFFF, 0xFE00, 0xFF00}: +
Set A = A' with upper bits replaced by A_upper_bits +
For each read instruction: read directly from A, sigupd(value) +  record any traps. +
For each write instruction: write unique known  value_new to A, then read back from scratch (A'), sigupd(value) +  record any traps. +
Instructions covered under this loop: +
(LOAD/STORE): Reads: {lb/lbu, lh/lhu, lw/lwu, ld}. Writes: {sb, sh, sw, sd}. +
(ATOMIC OPS): Each AMO is both a read and write, we will treat it as write: perform AMO at A, read back from scratch. If RV64A: {AMOSWAP.W/D, AMOADD.W/D, AMOXOR.W/D, AMOAND.W/D, AMOOR.W/D, AMOMIN.W/D, AMOMAX.W/D, AMOMINU.W/D, AMOMAXU.W/D}. +
If Zacas: {AMOCAS.W/D/Q}. +
If Zabha: {AMOSWAP.B/H, AMOADD.B/H, AMOXOR.B/H, AMOAND.B/H, AMOOR.B/H, AMOMIN.B/H, AMOMAX.B/H, AMOMINU.B/H, AMOMAXU.B/H}. +
(FLOATING POINT OPS): Reads: { FLW (F), FLD (D), FLQ (Q) } . Writes: {  FSW (F), FSD (D), FSQ (Q). } +
(COMPRESSED OPS): If Zca , Reads: {C.LW, C.LD, C.LWSP, C.LDSP}. Writes: {C.SW, C.SD, C.SWSP, C.SDSP}. +
If Zcd , Read: C.FLDSP. Write: C.FSDSP. +
(CACHE MANAGEMENT OPS): If Zicboz: perform CBO.ZERO at A  (write), read back from scratch using lw/ld. +
If Zicbom: perform {CBO.CLEAN, CBO.FLUSH} at A (write), read back from scratch. +
If CBIE enabled: perform CBO.INVAL at A, read back from scratch. +
If Zicbop: perform {PREFETCH.R, PREFETCH.W, PREFETCH.I} at A, then do a normal load/store at Scratch to observe cache effect. +
(VECTOR OPS): If ZVL32b/RVV 1.0,  Reads: {vleXX.v, vlseXX.v, vluxeiXX.v, vloxeiXX.v, vlsegNfXX.v, vl1r.v, vleXXff.v} from A, sigupd. Writes: {vseXX.v, vsseXX.v, vsuxeiXX.v, vsoxeiXX.v, vssegNfXX.v, vs1r.v} to A, read back from scratch sigupd(value) +  record any traps. +
(SHADOW STACK : Zicfiss): Writes/AMOs: SSPUSH/C.SSPUSH at A, then SSPOPCHK/C.SSPOPCHK from scratch to verify. SSAMOSWAP.W/D at A, read back from scratch.
