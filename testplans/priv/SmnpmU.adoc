[[t-SmnpmU-coverpoints]]
No smnpm coverpoints (no s mode) have been defined yet.

* Smnpm is a machine level extension which  enables pointer maksing for lower priviledge level S mode (if implemented ) or otherwise U-mode via menvcfg.
* In this sheet , test plan is for U-mode  implementation (SmnpmU), i.e if S mode is not supported.
* Similar to Ssnpm except:
* If S-mode not supported, run the same coverpoints as Ssnpm in U-mode except
* the JALR cross is kept separate from MXR as it is read-only zero if S-mode is not supported , since implicit fetch must be verified as never masked regardless of whether S-mode (and hence MXR) is implemented.
* - all addresses are physical, Tests executed only in Bare mode .
* - For cp_hardware_csr_write_faults , traps are being handled in M mode and mtval will be checked.
* - drop cp_pmm_mxr becuase MXR is read-only 0 if S-mode is not supported
