# Sm: rule-derived tests for the machine-level ISA

One test per `norm:` rule in `src/priv/machine.adoc`, generated by `tests_ai/gen/gen_Sm.py` (helpers in
`gen/smlib.py`). The Physical Memory Protection rules, the rules whose effect is only visible through PMP (MPRV, the
misaligned-portion mtval, the variable-length fetch xepc/xtval) and the Smepmp `mseccfg` fields are in
[`../PMP`](../PMP/README.md), generated by the same script (`gen/pmplib.py`).

## How the machine level is tested

- **Modes.** Every test boots to M-mode and requires `Sm`. S and U are entered with MRET (or SRET from M-mode) and
  left with a T-SBI GOTO; mode-dependent cases run under `#if S_SUPPORTED` / `U_SUPPORTED`. Only the `X_SUPPORTED`
  macros, `__riscv_xlen`, the privileged-version macros (`SM1P12P0_OR_LATER_SUPPORTED` for mconfigptr,
  `SM1P13P0_OR_LATER_SUPPORTED` for medelegh) and the `rvmodel_macros.h` addresses (mtime, mtimecmp, msip, the
  external-interrupt macros, the access-fault address) are configuration inputs.
- **WARL fields.** Each field is written with every interesting value and read back; an illegal value must read back
  as one of the legal ones. Features that are optional (writable misa letters, mtvec modes, delegation bits,
  counter enables, xBE bits, mcountinhibit, CBIE values, RLB/MMWP) are probed and both outcomes get their own
  expectations (`smlib.either`, which also allows `#if` guards inside a run-time branch).
- **Read-only zeros.** Fields of absent features (SIE/SPIE/SPP/TSR without S, MPRV/TW without U, MXR/SUM/TVM without
  a translation mode, FS/VS without F/V and S, menvcfg fields of absent extensions, USEED/SSEED, mie S bits, LCOFIE)
  are set and must read 0.
- **Traps.** ebreak, ecall (T-SBI ECALL_TEST), an illegal instruction with bit 31 set (`csrrw x0, cycle, x0`),
  `c.fld` with FS = Off, misaligned and access-fault loads/stores/LR/SC/AMOs are taken from M, S and U. The trap log
  gives the cause, xepc, xtval, the handler mode and xstatus on entry (xPIE/xIE/xPP checks). Delegation uses
  medeleg[3] and mideleg[1]/[5].
- **Interrupts.** Sources are mip.SSIP/STIP/SEIP (written by M-mode; Sstc's STCE is cleared first) and the platform's
  MSI, MTI, MEI and S-level external interrupt. Sweeps cover mode x MIE x mie bit x mideleg; several pending
  interrupts are released together and their order read back from the trap log; the trap log's vector field shows
  whether mtvec Direct/Vectored entered at BASE or BASE + 4 x cause.
- **Counters.** mcycle/minstret writes (a written minstret is read back exactly), the carry into bit 32, the RV32 high
  halves, mcountinhibit, mhpmevent = 0, and mcounteren from S and U (with scounteren = all ones).
- **misa.** MXL, E/I, reserved letters, the reset value of every letter, disabling M, F, D and C (C at a 2 mod 4
  address must be suppressed), and the F/D dependency.
- **Mutation check.** `MUTANTS` in `gen_Sm.py` (and `pmplib.MUTANTS`) are expectation switches read through
  `smlib.mut()`. Every mutant fails a test on Sail (or, for the PMP-grain mutants, on a DUT with G > 0).

## Subtleties

- Delegation-dependent interrupt cases read mideleg back: lower-level bits may be read-only 0 or 1
  ([#2675](https://github.com/riscv/riscv-isa-manual/issues/2675)). senvcfg's CBO enables are read back too before
  U-mode cases expect a CBO to execute.
- PMP CSRs may be absent on a hart with no PMP entries (cvw-rv32imc traps on pmpcfg0); the PMP tests probe them in
  a trap window first.
- After a T-SBI GOTO back to M-mode the framework leaves mstatus.MIE = 1, so every interrupt case clears MIE before
  making anything pending.
- While mstatus.MBE = 1 no table load may run (AI_LOAD would read big-endian), so the test clears MBE with `li`.
- `Zmmul_misa_m`: with Zmmul, multiplication stays legal while misa.M is clear
  ([#1711](https://github.com/riscv/riscv-isa-manual/issues/1711)); a config that lists Zmmul must run the DUT with
  it.
- A written minstret is read back exactly by the next instruction
  ([#1255](https://github.com/riscv/riscv-isa-manual/issues/1255)); mcountinhibit stops mcycle/minstret themselves
  ([#1420](https://github.com/riscv/riscv-isa-manual/issues/1420)).
- medeleg bits for exceptions that cannot occur need not be read-only zero
  ([#2675](https://github.com/riscv/riscv-isa-manual/issues/2675)); only medeleg[11] and [16] are checked.
- A misaligned AMO is accepted inside a 16-byte granule (Zama16b), so the AMO case crosses one.
- mtvec's vector number comes from the framework's trap log (word 0, bits 10:6), computed in `gen_Sm.vect()` from
  the trampoline layout in `tests/env/rvtest_trap_handler.h`.
