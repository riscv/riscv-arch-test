.ZicsrF Coverpoints
[cols="2,1,7", options=header]
|===
| Coverpoint | Goal | Feature Description

| cp_fcsr_access
| Writing to the CSR field +
(WARL)
| csr read, write all 1s, write all 0s, set all 1s, clear all 1s, write back inital value of each register: fcsr, fflags, frm

| cp_fcsr_frm_write
| Writing to the CSR field +
(WARL)
| Write 0-7 to fcsr.frm and read back fcsr and frm and fflags

| cp_fcsr_fflags_write
| Writing to the CSR field +
(WARL)
| Write 0-31 to fcsr.fflags and read back fcsr and frm and fflags

| cp_fcsr_walk
| Writing to the CSR field +
(WARL)
| Write walking 1s to fcsr, frm, fflags

| cp_frm_write
| Writing to the CSR field +
(WARL)
| Write 0-7 to frm and read back fcsr, frm, fflags

| cp_fflags_write
| Writing to the CSR field +
(WARL)
| write 0-31 to fflags and read back fflags, frm, fcsr

| csr_fflags_set_m_*
| Writing to the CSR field +
(WARL)
| Reset fflags to 0, then execute following instructions: 1/0 (DivZero), 1/3 (Inexact), largest + largest (overflow), smallest * smallest (underflow), infinity - infinity (invalid)

| cp_underflow_after_rounding
|
| Test each of the following floating-point operations does not set the underflow flag, even though it would if underflow were detected before rounding.  Note that these test cases are obtained from TestFloat. +
fma.s.rdn 3F00FBFF x 80000001 + 807FFFFF = 80800000 +
fmul.s.rup 00800001 x 3F7FFFFE = 00800000 +
if D supported: +
fma.d.rup 802FFFFFFFBFFEFF x 000FFFFFFFFFFFFE + 0010000000000000 = 0010000000000000 +
fmul.rdn 0010000000000001 x BFEFFFFFFFFFFFFE = 8010000000000000 +
fcvt.s.d.rne B80FFFFFFFFDFEFF = 80800000 +
if Q supported: +
fma.q.rdn 3F9800000000000001FFFFFFFF7FFFFE x 00000000000000000000000000000001 + 80010000000000000000000000000000 = 80010000000000000000000000000000 +
fmul.q.rne 0000FFFFFFFFFFFFFFFFFFFFFFFFFFFF x 3FFF0000000000000000000000000001 = 00010000000000000000000000000000 +
fcvt.s.q.rup 3F80FFFFFFFE0000000000FFFFFFFFFF = 00800000 +
If Zfh supported: +
fma.h.rne 0BC7 x 03FF + 8400 = 8400 +
fmul.h.rup 0401 x 3BF8 = 0400 +
fcvt.h.s.rne 387FF000 = *** +
Notes: +
sqrt, add, sub cannot cause underflow so are not tested +
TODO: Adding division underflow tests would be good +
No Zfa tests cause underflow

|===

[NOTE]
====
* These are unprivileged tests that should never trap.  Suitable for RVI20 and other systems with no machine mode.
* Tests run in M mode with mstatus.FS = 11 if Sm is supported, or else mode is not set
* fdiv.h.rne 07FF 4000 = 03FF
