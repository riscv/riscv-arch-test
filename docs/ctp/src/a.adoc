
=== A Atomic Extension

The A extension is subdivided into Zaamo and Zalrsc.

This section exercises unprivileged tests that will not trap.  Privileged tests are in other sections, such as ExceptionsZaamo.

==== Zalrsc Load-Reserved / Store-Conditional Extension

<<t-Zalrsc-coverpoints>> summarizes the coverpoints for the Zalrsc extension.

[[t-Zalrsc-coverpoints]]
.Zalrsc Instruction Coverpoints
include::{testplansdir}/Zalrsc.adoc[]

[[t-Zalrsc-coverpoint-definitions]]
.Zalrsc Coverpoint Definitions
[cols="2, 1, 4" options=header]
|===
|Coverpoint|Bins|Definition
3+^|cp_custom_lr coverpoints
|cp_custom_aqrl|3|none, aq, aqrl
|cp_custom_rd_edges|3|rd_value = 0, 1, -1
3+^|cp_custom_sc coverpoints
|cp_custom_aqrl|3|none, rl, aqrl. Each sc is retried in a constrained LR/SC loop of up to 100 attempts.
|cp_custom_sc_after_sc|2|sc followed by sc. The lr and both sc are retried, up to 100 attempts, until the first sc succeeds; the second sc must fail. This is not a constrained LR/SC loop, because the second sc follows the LR/SC sequence.
|cp_custom_sc_lr|2|lr followed by sc that fails and passes, sc pairs with most recent lr. The passing sc is retried in a constrained LR/SC loop of up to 100 attempts.
|cp_custom_sc_addresses|32*2|lr followed by sc at address of 8, ..., 248 offset from lr address.  For RV64, exercise both lr.d and lr.w. The sc may succeed if the reservation set includes its address, so it is retried up to 100 times. This is not a constrained LR/SC loop, because the sc and lr addresses differ.
|===

A single LR/SC pair may fail spuriously, and only a constrained LR/SC loop is guaranteed to succeed eventually. Therefore, every sc test that can succeed retries its lr/sc pair up to 100 times, including the standard register and value coverpoints of sc.w and sc.d.

include::norm/Zalrsc_norm_rules.adoc[]

The spec imposes no requirements on reservation set form, including alignment, NAPOT, or even being contiguous.  Therefore, it is not practical to build reference models that reliably predict whether a `sc` would succeed or fail on every DUT.  Current profiles require Za64rs or Za1284s, which can be supported by reference models. However, unusual DUTs that do not match any reasonable reference model may not be able to pass this test suite.
