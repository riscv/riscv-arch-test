# Ssccptr: rule-derived tests for hardware page-table reads from main memory

One test for the only `norm:` rule in `src/priv/ssccptr.adoc`. Generated by `tests_ai/gen/gen_Sx.py`. Mutants are
`Sx:walk_af` and `Sx:stale_pte`.

## How the extension is tested

- **Tables in main memory.** The tables are in the test image, which is in cacheable, coherent main memory on
  every configuration. Every walk through them must translate, with no access fault on the implicit reads.
- **Walks.** For each supported scheme (Sv32; Sv39, Sv48 and Sv57, each probed), 4 KiB and superpage leaves are used
  for loads, stores and fetches from S-mode, and for loads from U-mode.
- **Coherent reads.** After a PTE store and SFENCE.VMA, the walker must read the new PTE.
- **With H:** an HLV.W through VS-stage and G-stage tables. The VS-stage tables are themselves read through G-stage.
- **Leaves.** Every leaf has A=D=1. Ssccptr requires only page-table reads.

## Rules not tested here

- `pma_vm_hw_tbl_acc` (machine.adoc), which lets a region choose which page-table reads and writes it supports, is
  a permission.
- Main memory outside the test image is unknown to the test.

## Subtleties

- None.
