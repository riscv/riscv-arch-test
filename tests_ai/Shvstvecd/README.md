# Shvstvecd: rule-derived tests for vstvec Direct mode

One test per `norm:` rule in `src/priv/shvstvecd.adoc`. Generated by `tests_ai/gen/gen_Sx.py`, together with
Sstvecd, whose method it shares. Mutants are named `Sx:vs_<mutant>`.

## How the extension is tested

- **Where a trap lands.** `vstvec` is set to `Vtrampoline + 4k` (the framework's VS-mode spreader) with
  MODE=Direct. A VS-mode trap must run entry k, as recorded in the trap log.
- **Trap sources.** ebreak from VS and VU, sent to the VS handler with hedeleg[3]=1 (the framework sets hedeleg to
  0). A VS software interrupt raised through `hvip.VSSIP`, with hideleg[2]=1, `vsie.SSIE` and `vsstatus.SIE`.
- **MODE and read-back.** These are as in Sstvecd. `vstvec` is written from HS-mode.
- **Mutants:** an interrupt vectored in Direct mode, BASE[0] read-only 0, and Direct lost after Vectored.

## Rules not tested here

- All rules are tested.

## Subtleties

- Only addresses inside the image are used ([#3424](https://github.com/riscv/riscv-isa-manual/issues/3424)). The
  framework's `vstvec` is restored at the end.
