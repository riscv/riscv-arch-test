6+| Smmpm is a machine-level extension that provides pointer masking for M-mode.

6+| Exactly same coverpoints as Ssnpm except delete cp_pmm_uxl_clear, add the following, and run in M-mode:

6+| - all addresses are physical, all tests run in Bare/ M-mode .

6+| the JALR cross is kept separate from MXR and not guarded by S_SUPPORTED , since implicit fetch must be verified as never masked regardless of whether S-mode (and hence MXR) is implemented.
