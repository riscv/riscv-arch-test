=== Interrupts

The Interrupts suite has one covergroup per group of tests.  <<t-Interrupts_Sm-coverpoints,Interrupts_Sm>> boots to M-mode and exercises interrupts in every supported privilege mode; <<t-Interrupts-coverpoints,Interrupts>> boots to S-mode and exercises only the interrupts visible to supervisor software.  With the H extension, both cover the VS-level interrupts, including delegation to VS-mode through `hideleg`.  <<t-Interrupts_Sgei-coverpoints,Interrupts_Sgei>> and <<t-Interrupts_SgeiSm-coverpoints,Interrupts_SgeiSm>> cover guest external interrupts, and <<t-Interrupts_Shlcofideleg-coverpoints,Interrupts_Shlcofideleg>> and <<t-Interrupts_SmShlcofideleg-coverpoints,Interrupts_SmShlcofideleg>> cover the Shlcofideleg extension.  The groups whose names end in Sm require Sm, so they are not part of a certificate without Sm, such as RVA23.  The Sstc tests check access to the `stimecmp` register; the timer interrupts that `stimecmp` generates are covered by the `cp_trigger_sti_sstc` and `cp_write_stip_sstc` coverpoints of the Interrupts tests.

==== Interrupts Supervisor-Mode Interrupts

These tests are run on any configuration with supervisor mode that supports interrupts. They boot to S-mode and also run in U-mode (and VS/VU-mode when the H extension is supported); `mideleg` keeps its boot value with all supervisor-level interrupts delegated, except that with H and Sscofpmf, `cp_hideleg_lcofi_roz` clears `mideleg[13]` through a T-SBI call to check that bit 13 of `hideleg`, `hie` and `hip` is then read-only zero.

==== Sstc Supervisor Timer Compare

The Sstc suite has one covergroup per group of tests: Sstc_Sm_cg (M-mode) and Sstc_cg (S-mode and U-mode).
The Sstc_Sm tests require Sm, so they are not part of a certificate without Sm, such as RVA23.
