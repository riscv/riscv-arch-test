# Zvfh: rule-derived tests

One test per `norm:` rule of `src/unpriv/zvfh.adoc`. Generated by `tests_ai/gen/gen_Vzv.py`.

## How the extension is tested

- `Zvfh_instr`: one representative of every section the rule lists, at SEW=16: arithmetic (vfadd, vfmul.vf,
  vfmacc, vfsqrt, vfmin, vfsgnjn, vfclass, vmflt, vfcvt.x.f, widening vfwadd, narrowing vfncvt.f.f.w),
  single-width and widening reductions (vfredusum, vfredmax, vfwredosum), moves (vfmv.v.f, vfmv.s.f, vfmv.f.s; the
  f result must be NaN-boxed), vfslide1up.vf and vfslide1down.vf. Operands are exact, so the results do not depend
  on reduction order. fflags is checked after each instruction.
- `Zvfh_eew16`: the binary16 format, one element per instruction so each case's flags are checked: rounding at 11
  bits (ties to even), overflow (65504 + 16: infinity under RNE, 65504 with NX only under RTZ), subnormals (exact
  2^-24 + 2^-24, underflow of 2^-24 * 0.5 by rounding mode), the canonical NaN 0x7e00 (inf - inf, sNaN input),
  division by zero, and a NaN-boxed binary16 scalar.
- `Zvfh_instr_cvt`: the SEW=8 conversions: vfwcvt.f.x.v / vfwcvt.f.xu.v (exact), vfncvt.x.f.w / vfncvt.xu.f.w with
  ties, saturation and NaN (NV), and the rtz forms (truncate whatever frm says).
- `Zvfh_dependent_Zve32f_Zfhmin`: Zve32f's vfadd at SEW=32 and Zfhmin's flh/fsh/fcvt.s.h/fcvt.h.s.
- Expected values are computed with exact rational arithmetic and IEEE 754 rounding (tininess after rounding) in
  `vzvlib.py`, not with a model.

## Rules not tested here

None. Value crosses of the vector FP instructions are left to the ACT Vf test plan.

## Subtleties

- With RTZ, 65504 + 16 = 65520 rounds to 65504, which does not exceed the largest finite value, so OF is not raised
  (IEEE 754 overflow is judged on the result rounded with an unbounded exponent).
