|===
|Coverpoint|Bins|Definition
3+^|Zacas Value Comparison Coverpoints
|cmp_rd_rs1_val_eq|2|original rd value and rs1 value are equal/not equal.
|cmp_rd_rs1_val_lsb|2|Least significant byte of original rd and rs1 are equal/not equal.
|cmp_rd_rs1_val_hw|2|Lowest 16 bits of original rd and rs1 are equal/not equal.
|cmp_rd_rs1_val_w|2|Lowest 32 bits of original rd and rs1 are equal/not equal.
|cmp_rd_rs1_pair_partial_val|2|For register pairs, original rd and rs1 have matching high or low halves, but not both.
|cmp_rd_sign_ext|2|Value loaded into rd by amocas.w is sign-extended from bit 31 or not.
