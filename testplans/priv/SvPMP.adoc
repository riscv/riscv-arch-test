7+| General Test Environment (SvPMP): +
- Boots to M-mode (legacy mode hops) because each test programs PMP entries, which are M-mode CSRs. Unchanged by the T-SBI conversion. Run for every supported translation mode: Sv32 on RV32; Sv39, Sv48 and Sv57 on RV64, as selected by the UDB configuration.

| mode
| Verify each supported translation mode is exercised with PMP
| Sampled while the SvPMP tests run under satp.MODE = Sv32, Sv39, Sv48 or Sv57.
| Every supported mode is observed.
| mode {sv57, sv48, sv39, sv32} +
= 3 bins on RV64, 1 on RV32
