
=== C Compressed Extension

The C extension is subdivided into Zca, Zcf, and Zcd.  All configurations supporting C contain Zca.  RV32CF configurations also contain Zcf, and RV{32/64}CD configurations also contain Zcd.  A configuration supporting C should test all of the applicable Zc* extensions.

Compressed-instruction behavior that traps (reserved encodings, illegal instructions, misaligned and faulting loads and stores) is covered by the ExceptionsZc (<<t-ExceptionsZc-coverpoints>>) and SsstrictS (<<t-SsstrictS-coverpoints>>) test plans. <<t-ExceptionsZc-normative-rules>> summarizes the normative rules for compressed-instruction exceptions.

==== Zca Compressed Extension

<<t-Zca-coverpoints>> summarizes the coverpoints for the Zca extension.
These include the standard compressed HINTs in the cp_c_hint_* family.  Note that some of these HINTs (`c.add x0, x2`-`x5`) are also Zihintntl HINTs.
The `c.slli`, `c.srli`, and `c.srai` HINT encodings (shamt = 0, and `c.slli` with rd = x0) are designated for custom use, so they are deliberately not tested.
