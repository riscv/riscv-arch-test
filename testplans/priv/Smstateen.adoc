| Access successful
| 4-8 CSRs * 128-64 walking ones/zero

| Each stateen CSR allows read/write access from its own and higher privilege modes and denies read/writeaccess from lower privilege modes

For RV32, also write msstateen0-3h
| Illegal instruction
| 4-8CSRs

smstateen_illegal_state_access

| mstateen0-fcsr_roz

|

| stateen0-jvt_op

| With mstateen0.envcfg = {0,1}, read and write sevncfg from  M, S if supported, else U

| 2 states x 2 accesses
| mstateen0-envcfg_op

| cp_csrind
| csrind controls access
| If Sscsrind supported: +
With mstateen0.CSRIND = {0, 1}, read and write siselect.  And with siselect having some value TBD, write and read sireg, +
sireg2, sireg3, sireg4, sireg5, sireg6.  M, S if supported, else U
| Always successful
| 2 states x 2 accesses x 6 regs
| mstateen0-csrind_op

| aia controls access

| mstateen0-aia_op

| cp_imsic
| ismic controls access
| If IMSIC supported: +

| 2 states x 2 accesses x ? regs
| mstateen0-imsic_op

| mstateen0-context_op

mstateen_ctr0

mstateen0-se0_op
