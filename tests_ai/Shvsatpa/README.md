# Shvsatpa: rule-derived tests for vsatp modes

One test for the only `norm:` rule in `src/priv/shvsatpa.adoc`. Generated by `tests_ai/gen/gen_Sx.py`. Mutants:
`Sx:vsatp_missing_sv57`, `vsatp_missing_sv32` and `vsatp_ignored`.

## How the extension is tested

- **Every satp mode.** For each mode that satp accepts (Sv32; Sv39, Sv48, Sv57), vsatp must accept it.
  - vsatp is written from HS-mode, where a write with an unsupported MODE has no effect
    (`vsatp_mode_unsupported_v0`), so MODE reads back only if supported.
- **The mode translates.** With hgatp Bare, HLV.W of an upper-half virtual address (which uses the mode's top VPN
  bits) reads the mapped page. With the leaf made invalid it raises a load page fault, so the table is really used.
