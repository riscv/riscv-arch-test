| Coverpoint | Goal | Feature Description | Expectation | Bins

| cp_instr_page_fault_m
| Instruction Page Fault
| jump to address that would cause instruction page fault in non-M-mode because mstatus.MPRV=1 and  mstatus.MPP={01, 00}, but no fault occurs because MPRV should not affect instruction fetch in M-mode.
|
|

| cp_load_page_fault_m
| Load Page Fault
| load from address that causes load page fault because mstatus.MPRV=1 and  mstatus.MPP={01, 00}
|
|

| cp_store_page_fault_m
| Store Page Fault
| store to address that causes store page fault because mstatus.MPRV=1 and  mstatus.MPP={01, 00}
|
|

| cp_misaligned_priority_m
| Priority of exceptions
| Attempt lw and sw and fetch from memory location causing {access fault and page fault}, {page fault and misaligned}, {access fault, page fault, misaligned}
| M-mode needs MPRV to S or U mode to be able to cause access fault.  No fetch fault occurs because MPRV does not affect fetch privilege.
|

| cp_medeleg_m
| Machine mode exception not affected by medeleg
| Attempt instruction/load/store page faults crossed crossed with medeleg = [ {1011_0011_1111_1111}, {0}, and 13 different walking 1s]
| medeleg should not affect machine mode exceptions.  No instruction page fault occurs because MPRV does not affect fetch privilege.
|

| cp_misaligned_load_page_fault_s
| Page fault on each part of a misaligned access
| Check behavior of a misaligned load spanning a page boundary, in which one of the two pages faults. +
Set up two consecutive virtual kilopages, with both combinations of one page RWX=111 and the other RWX=000. +
Issue misaligned lw crossing page boundary. +
If misaligned accesses are supported, expect a misaligned load fault. +
If misaligned access is supported, expect a load page fault. +
MTVAL could be 0, or should be the address of the load if the fault occurs in the first page, +
or the address of the start of the second virtual page if the fault occurs in the second page.
|
| 2 bins

| cp_misaligned_store_page_fault_s
| Page fault on each part of a misaligned access
| Same as cp_misaligned_load_page_fault_u but with sw and store faults.
|
| 2 bins

| cp_misaligned_instr_page_fault_s
| Page fault on each part of a misaligned instruction
| Same setup as cp_misaligned_load_page_fault_s +
Issue jalr to 4-byte instruction on odd multiple of 2 address spanning the two virtual pages. +
If Zca is not supported, expect a misaligned instruction fault. +
If Zca is supported, expect a instruction fetch page fault. +
See cp_misaligned_load_page_fault_s about possible MTVAL outcomes.
|
| 2 bins
